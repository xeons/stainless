Installing Stainless
====================

`stainless` (`stainless.exe` on Windows) is the whole compiler: one
self-contained file with the runtime and the standard library inside it. It
needs no .NET install. Put this directory somewhere and add it to PATH.

It does need clang, because it hands its LLVM IR to clang to compile and link.

    Windows         winget install LLVM.LLVM
    Debian, Ubuntu  sudo apt install clang
    macOS           brew install llvm

STAINLESS_CLANG names the clang to use and always wins. Otherwise, on macOS,
Homebrew's LLVM comes first, because Apple's clang is on PATH and is not the
supported one. Then the first clang on PATH is used, then
C:\Program Files\LLVM\bin on Windows, or /usr/bin/clang and
/usr/local/bin/clang elsewhere. On Windows, clang also
needs the Windows SDK and the MSVC libraries, which Visual Studio or its
Build Tools install.

Then:

    stainless run samples/hello.sl
    stainless run samples/tour
    stainless --help

stainless-ide (stainless-ide.exe on Windows) is an editor for Stainless,
written in Stainless: syntax colouring, building and running, the compiler's
diagnostics in place, a debugger and a form designer. It finds the compiler
beside itself, so keep the two in the same directory. Open a project or a
file with it:

    stainless-ide samples/tour

On Linux it needs GTK 3, which a desktop already has (libgtk-3-0 on Debian
and Ubuntu). The macOS archive carries no IDE yet.

On macOS the binary is signed ad hoc and not notarized, so an archive a
browser downloaded is quarantined and Gatekeeper refuses to run it. Clear the
flag once, after unpacking:

    xattr -dr com.apple.quarantine stainless-*

There is no archive for an Intel Mac. The compiler can build Intel code with
--target x64-macos, from an Apple silicon Mac or from source on an Intel one.

bindings/ and forms/ are source, compiled into a program that names them.
A GTK program on Linux needs the GTK 3 development packages and the libraries
named on the command line; bindings/gtk/README.md has the list.

docs/ is the language and the tools; README.md is the place to start.
